One original one-line dad joke for make.fun's The One-Liner Groan-Off: a familiar saying taken literally, delivered by a dad at the dinner table. The program writes the single line to /output/entry.txt. The line was picked from about 290 screened candidates across 13 families, each checked against the judge's five criteria and against circulating joke lists.

## Run it

```sh
python3 main.py
```
